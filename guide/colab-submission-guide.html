If something goes wrong

Colab won't accept the file

Check the name ends in .ipynb. If WhatsApp added .txt to the end, rename the file and delete the .txt.

Nothing happens after Run all

Wait 30 seconds. Check the top right says Connected. Then click Runtime, then Run all again.

The PDF has blank areas or missing results

Go back to Colab, run everything again, wait until every box shows results, then print again.

You closed Colab by mistake

Upload the same file again and start from Part C. Nothing is lost.

Code lines are cut off in the PDF

In the print window, change Scale to 90 and save again.
